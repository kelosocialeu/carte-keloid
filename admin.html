Administration de la carte

Modifie le statut, la couleur et la date prévisionnelle de chaque pays. Les changements enregistrés dans le dépôt seront publiés avec le prochain déploiement Vercel.

Connexion à GitHub

Le dépôt sert de stockage partagé pour la configuration. Utilise un jeton GitHub à accès limité au dépôt kelosocialeu/carte-keloid, avec l’autorisation Contents: Read and write. Le jeton reste uniquement en mémoire dans cette page et n’est pas sauvegardé dans le navigateur.

Accès administrateur : seules les personnes disposant d’un jeton valide avec accès en écriture à ce dépôt peuvent publier des modifications. Ne partage jamais ce jeton. Il n’est pas envoyé à un autre service que l’API officielle de GitHub.
